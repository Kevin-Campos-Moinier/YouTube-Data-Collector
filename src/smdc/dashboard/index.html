Connect your YouTube API key

The tool reads public comments through YouTube's official API, with a free key of your own. Getting one takes about five minutes, once.

  1. Create a project in the Google Cloud console. A dedicated Google account is a good idea.
  2. Enable the YouTube Data API v3 for that project.
  3. In Credentials, choose Create credentials, then API key. If asked what data you will access, choose Public data.
  4. On the key, choose Edit, then under API restrictions restrict it to the YouTube Data API v3 and save. Leave Application restrictions on None.
  5. Paste the key here.

The test costs 1 unit of the key's daily quota. The key is saved in , readable by you only. It stays on this computer, is sent to YouTube alone, and is never shown again.
